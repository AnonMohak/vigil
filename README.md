# Vigil

A first-person walk through a gothic nave at night, lit by candles and moonlight through stained glass.

- `public/` is the static site: `index.html`, `main.js` (three.js 0.170 from jsDelivr) and `assets/`.
- `blender/` is the source: Python scripts that build the scene, bake the lighting and export it.

## Run locally

```
python -m http.server 8765 --directory public
```

Open http://127.0.0.1:8765 and click **Enter**.

You walk on rails down the centre of the aisle; only the part of your view along the nave moves you.

- Desktop: W forward, S back, mouse to look, Shift to hurry, E to sit in the pew beside you (E again to stand),
  M to mute the music.
- Phone: move the phone to look (gyroscope), hold the top half of the screen to walk on and the bottom half to step
  back, drag sideways to turn, tap **Sit** beside a pew.

The music is `public/assets/audio/ambient.m4a`, made from the original `bg.mp3` (since removed) with:

```
ffmpeg -i bg.mp3 -ss 0.85 -af "afade=t=in:d=2.5,afade=t=out:st=663.5:d=5.5" -c:a aac -b:a 80k -movflags +faststart public/assets/audio/ambient.m4a
```

## Rebuild from Blender

In Blender 5.1 (Cycles, a CUDA GPU helps), run the scripts in order from the Python console:

```python
D = r"C:\Users\mohak\projects\cc-no-404\gothic\blender\\"
run = lambda f, main=True: exec(open(D + f).read(), {'__name__': '__main__' if main else 'lib'})
run('build_church.py')     # geometry, candles, lights
run('materials.py')        # stained glass textures, materials, world, haze
```

Then bake and export (about 10 minutes on a GTX 1060):

```python
g = {'__name__': 'lib'}; exec(open(D + 'bake_export.py').read(), g)
for n in g['LIGHTMAPS']: g['lightmap_uv'](n)
for n in g['LIGHTMAPS']: g['bake_one'](n, 128)
g['export_glb']()
```

The lightmaps hold diffuse light only (direct and indirect), denoised with OIDN and stored as sRGB of
`L / 0.6`. `main.js` multiplies them back with `lightMapIntensity = 0.6 * PI`. The roof in Blender exists
only to keep moonlight out of the space above the vaults during the bake; it is not exported.

Wear comes from `weather()` in `build_church.py` (chipped edges on stone and wood), drum joints on the piers,
floor slabs that follow the joints of the floor texture (each one a little out of level, with its own tint),
and a grime shader in `main.js` (damp near the floor, run-off streaks, stains).
